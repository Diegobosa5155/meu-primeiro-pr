# Meu Primeiro PR

Este é um repositório de teste para praticar o fluxo de Pull Request no GitHub.

## Como usar este repositório

1. Clone o repositório
2. Crie uma branch para sua alteração
3. Faça o commit das mudanças
4. Abra um Pull Request
5. Revise e faça o merge

Esse fluxo é o mesmo que usaremos depois em projetos reais da Bassano Esquadrias.
